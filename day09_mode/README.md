# 第九天：手动与自动模式

Arduino Uno / PlatformIO / Wokwi，串口 9600。

- 初始：手动模式，灯灭。
- 1 / 0：退出自动模式，开灯 / 关灯。
- a：保留当前亮灭状态，进入自动模式，1 秒后首次切换，此后每隔 1 秒切换。再次发送 a 会重新计时。
- ?：查询模式与灯状态，不改变控制状态。
- 按键确认按下：退出自动模式，切换当前灯状态；长按不重复触发。
- 忽略回车换行；其他字符提示 Unknown command。

接线继承第八天：POWER 5V → 1000Ω → LED A，LED C → D8；LOW 亮、HIGH 灭。
D2 → 按键 1.l，GND → 2.r；INPUT_PULLUP，按下 LOW。消抖连续稳定至少 20 ms。
程序依次处理串口、按键、自动计时，不使用 delay()。

## 运行

VS Code 打开本目录，PlatformIO Build，等待 SUCCESS。
Ctrl+Shift+P → Wokwi: Start Simulator。修改代码后需重新编译再仿真。

## 验收记录（2026-11-04）

1. 启动灯灭，查询 MANUAL / OFF。
2. 发送 a，约 1 秒后灯亮，此后每秒切换。
3. 发送 0，灯灭；等待 3 秒仍灭，查询 MANUAL / OFF。
4. 发送 1，灯亮；等待 3 秒仍亮。
5. 发送 a，再按一下按键，切换当前亮灭并回到 MANUAL；等待 3 秒保持。
6. 长按只触发一次，松开不切换；按住期间仍可用串口 0 关灯。
7. 发送 x 报错，不改变模式或灯状态。

本次聊天中，学习者确认启动、自动闪烁、串口 0 接管关灯与查询、按键接管、长按一次、按住期间串口关灯、松开再按及非法命令测试均符合预期。串口 1 单独测试列为补充检查，尚无单独反馈。

## 核心理解与编译记录

进入自动模式时记录 previousLedMillis = millis()，保证首次切换也等待完整 1 秒；若保留过期时间，可能立即切换，随后恢复每秒切换。记录时刻不会重置 millis()。
