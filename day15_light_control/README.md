# 第十五天：用 ADC 做光控夜灯

Arduino Uno / PlatformIO / Wokwi，串口 9600。这个独立实验保留第十四天的 D9 低电平点亮接法，使用光敏模块替代电位器。

- 光敏模块 VCC → 5V，GND → GND，AO → A0，DO 不接。
- LED：5V → 1000Ω → 阳极，阴极 → D9；D9 LOW 亮、HIGH 灭。
- 这个模块的 ADC 读数随环境变暗而增大。ADC 读数不是 lux；lux 是仿真中设置的照度。
- 每 100 ms 采样一次，每 1000 ms 打印一次读数和灯的状态。无需输入命令。

灯灭时，ADC ≥ 600 开灯；灯亮时，ADC ≤ 450 关灯。451～599 保持原状态，这就是迟滞区间。这样小幅波动不会让灯在一个临界点反复开关。

## 运行与验收记录

PlatformIO Build → SUCCESS → Ctrl+Shift+P → Wokwi: Start Simulator。点击光敏模块调照度，查看 Wokwi Terminal 的读数，并观察外接红色 LED（不是模块自带指示灯）。

| 顺序 | 照度 | 参考 ADC | 预期灯状态 |
| --- | ---: | ---: | --- |
| 1 | 400 lux（初始） | 281 | 灭 |
| 2 | 100 lux | 511 | 保持灭 |
| 3 | 50 lux | 633 | 亮 |
| 4 | 100 lux | 511 | 保持亮 |
| 5 | 400 lux | 281 | 灭 |

参考读数来自 Wokwi 光敏模块文档；实验以实际读数和阈值为准。
https://docs.wokwi.com/parts/wokwi-photoresistor-sensor

学习者确认变暗开灯、变亮关灯以及表中的迟滞测试均符合预期：从明处调到中间区间保持灭，从暗处调到同一区间保持亮。表中 ADC 数字是参考值，不是单独记录的实测数值。PlatformIO 编译成功（RAM 199/2048 字节，Flash 2522/32256 字节）；归档时未重新运行仿真。

## 代码阅读笔记

- 光敏模块用固定电阻和光敏电阻分压：5V → 10 kΩ → AO → 光敏电阻 → GND。在此接法中，环境变暗使光敏电阻变大，AO 电压和 ADC 读数随之升高。
- analogRead(A0) 得到 ADC 数值，供程序比较两个阈值；模块的 DO 只给一个高低电平，本实验未使用。
- digitalWrite 控制外接 LED 全亮或全灭。处于迟滞区间时，两条切换条件都不成立，保留 ledOn 和 D9 输出。
