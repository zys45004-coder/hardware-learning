# 第二十天：定时光控夜灯

Uno R3 / PlatformIO / Wokwi。LCD (0x27) 和 DS1307 (0x68) 共用 A4/SDA 与 A5/SCL。光敏模块 AO 接 A0；LED 阴极接 D9，低电平点亮。

- 允许时段：每天 18:00（含）至次日 06:00（不含）。
- 时段外强制关灯；时段内 ADC >= 600 开灯，ADC <= 450 关灯，中间区间保持原状态。
- 上电时灯灭。如果 RTC 初始化失败、检测到 I2C 超时或读到无效时间，本次时段判断禁止开灯。
- 每约 100 ms 检查光照，约每秒读时钟和更新屏幕。LCD 第一行显示时间和时段，第二行显示 ADC 和灯的状态。

## 复现实验：傍晚边界

Ctrl+Shift+P → Wokwi: Start Simulator。不操作光敏模块。仿真预设 17:59:50 与约 50 lux，正常时 ADC 约 633。

1. 18:00 前：LCD 显示 DAY，外接灯保持灭。
2. 约十秒后跨到 18:00：LCD 显示 NIGHT，同样的光照下外接灯亮。
3. 夜间调亮到约 400 lux：ADC 约 281，灯灭；再调暗到约 50 lux，灯重新亮。

## 复现实验：早晨边界与夜间迟滞

如需测早晨边界，停止仿真，在 diagram.json 中将 rtc1 的 initTime 临时改为 2026-11-14T05:59:50，再启动。保持约 50 lux：06:00 前亮，06:00 起灭。结束后恢复原 initTime。

在允许时段内，从亮处和暗处分别调到约 100 lux（约 511），应分别保持灭、保持亮。此处读数是参考值。

## 已确认的仿真结果

- 傍晚边界：照度保持在 50 lux，18:00 前显示 DAY 且灯灭，跨到 18:00 后显示 NIGHT 且灯亮。
- 夜间光控和迟滞：依次调到 50 → 100 → 400 → 100 → 50 lux，观察到亮 → 保持亮 → 灭 → 保持灭 → 亮。
- 早晨边界：照度保持在 50 lux，06:00 前灯亮，进入 06:00 后自动关灯。
- 提交前核对仿真配置已恢复 17:59:50、50 lux。ADC 数字是参考值，不是单独记录的实测读数。

三组由学习者确认符合预期。PlatformIO 编译成功（RAM 484/2048 字节，Flash 9004/32256 字节）；归档未重新运行仿真。

## 代码阅读笔记

- 跨午夜时段用 hour >= 18 || hour < 6 表达。白天强制关灯，夜间再按两个 ADC 阈值处理。
- Wire 超时标记由 Uno 的 I2C 接口共用；读 RTC 前清除旧标记，读完再检查。未超时不等于通信一定成功；NACK 可以在应答时钟周期立即返回。
- RTC 日期合法不代表时钟已经校准。toString 按格式模板就地替换数字字符，例如 hh:mm:ss 变为 18:05:09。
