# 第十四天：ADC 读取电位器与 PWM 调光

Arduino Uno / PlatformIO / Wokwi，串口 9600。
沿用 D9 低电平点亮 LED、D2 上拉按键。新增电位器：VCC → 5V、GND → GND、SIG → A0，初值约在中点。

发送 adc，读取 A0 一次，打印 0～1023 的原始值，以及按 5 V 参考电压换算的近似毫伏数。adc 命令只报告一次测量结果。用 pot 开启旋钮调光；其他第十三天命令保持可用。

Ctrl+Shift+P → Wokwi: Start Simulator。点选旋钮后可用 Home 和 End 调到两端，方向键可微调。输入命令前点击 Wokwi Terminal 以切回终端焦点。

## ADC 读数参考

- 中点：adc 约 512，约 2500 mV。
- 最小端：adc 约 0，约 0 mV。
- 最大端：adc 约 1023，约 5000 mV。

显示的毫伏数是用 ADC 读数换算的估计值。

## 旋钮调光与验收

- 先发 on，再发 pot。之后程序每隔 50 ms 读取 A0，用 ADC 读数换算亮度，灯亮时立即更新 D9 PWM。旋钮两端对应 1% 和 100%，中点约 50%（读数 512 时是 51%）。status 显示 Source: POT。
- 发 off 后转旋钮：灯保持熄灭；再发 on，使用当时的旋钮亮度。旋钮改变亮度，不改变手动或自动模式。
- 发 brightness 25：切回串口设置，随后转旋钮不再改变亮度。status 显示 Source: SERIAL。无效 brightness 参数不切换来源。
- 重启后默认使用串口亮度 100%，EEPROM 仍只保存闪烁间隔。

学习者确认：中点读取与旋钮两端亮度对比符合预期；切回串口后旋钮不再改亮度；熄灯时旋钮可以更新亮度设置而不点灯，重新打开后使用当前旋钮设置；自动模式下旋钮调光不改变亮灭节奏。以上是课堂反馈，未单独记录两个端点的 ADC 原始数值。PlatformIO 编译成功（RAM 736/2048 字节，Flash 4964/32256 字节），归档时未重新运行仿真。

## 代码阅读笔记

- VCC 和 GND 是电位器电阻轨道的两端，SIG 是滑动触点，A0 测量 SIG 相对于 GND 的电压。
- analogRead 返回 0～1023 的原始整数。程序按 5 V 参考电压估算毫伏，显示到 1 mV 不代表测量精确到 1 mV。
- 旋钮调光直接将原始读数映射到 1%～100%，无需先换算电压。D9 的低电平占比控制亮起时的亮度；开关和自动闪烁逻辑独立。
- 课堂另讨论了 0～10 V 信号：必须先用合适的分压电路再接 Uno A0。A0 电压换算仍用约 5 V 参考电压，估算分压前的信号还需乘上分压比例的倒数。当前工程仍采用 0～5 V 接线。
