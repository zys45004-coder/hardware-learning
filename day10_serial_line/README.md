# 第十天：串口整行命令

Arduino Uno / PlatformIO / Wokwi，波特率 9600。
沿用第九天接线与按键消抖：D8 LOW 亮、HIGH 灭；D2 INPUT_PULLUP，按下 LOW。

## 命令

每条命令以 CR、LF 或 CRLF 结束，兼容 VS Code Wokwi 终端 Enter。点击终端黑色文字区域后输入；程序回显收到的可打印英文字符，并支持普通退格。不要手动键入反斜杠和 n。

- on：手动模式，开灯。
- off：手动模式，关灯。
- auto：保留当前亮灭，重新计时，1 秒后首次切换，之后每秒切换。
- status：查询模式与亮灭。

仅接受上面的小写完整命令，无首尾空格。旧命令 1/0/a/? 本日不再支持。
空行忽略；非法命令返回 Unknown command，不执行控制动作。
32 字符数组最多保存 31 个内容字符，预留一个位置存放字符串结束符。
超长命令整行丢弃，在回车或换行时提示 Command too long，下一行正常接收。
输入错误不会改变模式；若此前处于自动模式，自动计时仍照常运行。
按键确认按下后退出自动模式并切换灯，长按只触发一次。

## 核心流程

收到可打印英文字符 → 保存并回显；收到回车或换行 → 补字符串结束符 → strcmp 比较完整命令 → 清零长度。CRLF 的后半部分视为空行忽略。
换行符是通信中的行边界，字符串结束符是内存中文字的结束标志。
每轮最多接收一个字符，没有 delay，也不会停在接收函数中等待后续字符。

## 运行与验收记录（2026-11-05）

打开本目录，PlatformIO Build → SUCCESS → Ctrl+Shift+P → Wokwi: Start Simulator。
点击 Wokwi Terminal 的文字区域，输入命令后按 Enter。输入应可见；CR、LF 和 CRLF 均接受。

1. 初始 MANUAL / OFF。
2. on 开灯，status 返回 MANUAL / ON。
3. off 关灯，status 返回 MANUAL / OFF。
4. auto 自动闪烁；status 返回 AUTO 及当时状态。
5. 自动闪烁时按键接管，回到 MANUAL 并切换一次；等待 3 秒保持不变，status 返回对应状态。
6. abc 返回 Unknown command；空行无输出。
7. 输入 onn 后退格一次再按 Enter，按 on 执行开灯。
8. 发送 32 个 x 并按 Enter：Command too long；下一行 off 正常关灯。

## 输入问题与修正

VS Code Wokwi Terminal 中，输入可能没有本地回显。早期程序只接受 LF 并忽略 CR，可能与终端 Enter 不匹配。
最终版由程序回显收到的可打印英文字符，CR、LF 或 CRLF 均可结束命令；CRLF 的第二个字符不重复执行。支持退格（BS/DEL）。
超长行在结束前始终丢弃，避免将截断命令当成有效命令。只有收到行结束符后才恢复接收新命令。

## 核心理解

- 收到命令结束符之前继续等待，按键与自动计时仍继续处理。
- off 的三个字符占下标 0、1、2，字符串结束符放在下标 3。
- commandLength = 0 后，新命令从下标 0 覆盖，不必先清空整个数组。
- strcmp 返回 0 表示字符串内容相同；字符数组不可用 == 比较文字内容。
